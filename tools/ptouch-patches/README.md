# Patches for ptouch-print

Applied on top of the upstream tag with `git am` when ptouch-print is built with
`PTOUCH_PATCHES=1` (static build in `tools/ptouch-build`, contract test in `tools/contract`).

The patches change ptouch-print and are therefore under its license, the GPL-3.0
([../ptouch-build/licenses/ptouch-print.txt](../ptouch-build/licenses/ptouch-print.txt)), not
under Labeler's MIT license.
